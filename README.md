# 就到站 · 香港巴士

繁體中文巴士到站 PWA，可在 iPhone Safari、Android Chrome 使用及加入主畫面。

## 功能

- 九巴／龍運、城巴路線搜尋，支援路線號碼、起點和目的地。
- 車站／地點搜尋：以站名包含的地點或車站編號找九巴／龍運車站，選站後列出途經方向及特別班次，直接查看該站到站預報。同名車站分開顯示，可載入更多結果；不提供地址定位或城巴中途站搜尋。
- 各方向車站、九巴特別班次、最多未來三班預報，每 30 秒更新。
- 收藏指定路線、方向及上車站；附近及學校路線卡可直接按星星，保存在目前瀏覽器，不跨裝置同步。允許定位後，在附近、學校、收藏及路線車站顯示距你的約略直線距離（不是步行路線距離）。
- 預設開啟附近路線，請求單次定位搜尋 1 公里內最多 20 個九巴／龍運車站，自動列出途經路線及即時到站，按最快到站排序，同路線同方向只顯示最近上車站及最多三班預報；每 30 秒更新，附倒數及立即更新按鈕（同時重新定位及載入路線／到站資料）；開頁首 30 秒內失敗項目每 5 秒重試，不重疊發出未完成請求；更新失敗保留舊資料及標示時間；未有預報排最後。
- 附近路線支援頁頂單指下拉更新：拉到提示後放手，重新定位並更新巴士資料；短拉、橫滑、多指及頁面中段捲動不觸發。
- 「李炳中學」分頁：以「李炳中學門口」（TW310／TW311）及「對面車站」（TW496）兩個按鈕分開列出可風中學九巴／龍運車站的路線，按最快到站排序，每條路線每個方向最多三班，附每 30 秒更新、倒數、立即更新及失敗時保留舊資料，無需定位。
- PWA 主畫面圖示、離線應用外殼。即時到站不會離線快取。
- 少於或等於一分鐘顯示「即將到站」；無預報不推斷停駛，只有巴士公司明確標示才顯示「服務已結束」。附近、學校、收藏及路線到站面板更新失敗保留上次結果，顯眼標示舊資料及上次成功更新時間。

城巴附近車站、新大嶼山巴士、港鐵接駁巴士、小巴及跨裝置同步不在首版範圍。

## 技術

React 19、TypeScript、Vite 7、Bun。前端直接讀取官方公開 JSON，無需 API 金鑰或應用後端。官方端點支援 CORS。部署為靜態 `dist/`，可移植至其他 HTTPS 靜態託管服務。

- `src/lib/bus.ts`：官方資料轉換、方向／車站序號／班次篩選、距離計算。
- `src/pages/bus-app.tsx`：路線、到站、收藏、定位及安裝指引。
- `src/bus.css`：手機及桌面版外觀。
- `public/manifest.webmanifest`、`public/icons/`：PWA 資訊及圖示。
- `scripts/build-sw.ts`：建立版本化離線應用外殼，只快取本站資源，不快取到站 API。
- `.openai/hosting.json`：Sites 託管識別及靜態輸出設定。
- `server.ts`、`zosite.json`：保留原 Zo 開發框架及設定；Sites 靜態部署不使用此伺服器。

## 資料來源

- 九巴／龍運：https://data.etabus.gov.hk/v1/transport/kmb
- 城巴：https://rt.data.gov.hk/v2/transport/citybus
- 九巴開放數據及規格：https://data.gov.hk/tc-data/dataset/hk-td-tis_21-etakmb
- 城巴開放數據及規格：https://data.gov.hk/tc-data/dataset/ctb-eta-transport-realtime-eta

路線和車站資料在瀏覽器暫存 24 小時，到站資料每次向巴士公司即時查詢。按方向、車站序號及九巴服務類別篩選預報，避免循環路線同站重複或反方向資料混用。沒有預報不等同取消班次。此為非官方應用程式。

## 私隱

不要求註冊，不收集位置。開啟網站及按立即更新時會請求定位，首次失敗於首 30 秒內每 5 秒重試，不設重新定位按鈕或獨立車站列表；位置由裝置讀取，在裝置計算距離，不上傳到我們的伺服器。直接呼叫巴士公司 API 時，對方可見一般網絡連線資料。收藏及路線快取只在瀏覽器 localStorage；清除網站資料會移除收藏。

## 開發及驗證

```sh
bun install
bun run build
bunx tsc --noEmit
bun test
```

`bun run build` 產生 `dist/`，並建立 service worker。須在 HTTPS 或 localhost 使用 PWA；即時到站及首次下載路線需要連線。Zo 原有開發伺服器由平台管理，不應手動啟動 `bun run dev` 或 `bun run prod`。

原始碼儲存庫：https://github.com/lp-ICT/hk-bus 。網站：https://lp-ICT.github.io/hk-bus/ 。GitHub Pages 從 gh-pages 分支發佈建置後的網站；更新 main 後須重新驗證、建置並更新 gh-pages。以 `BASE_PATH=/hk-bus/ bun run build` 建立 GitHub Pages 版本；預設路徑仍適用其他靜態託管。

學校車站位置核對：https://liping.edu.hk/page/653 。校外站往荃灣／葵涌，對面站往沙田；站號及路線對應以九巴官方 stop、route-stop API 為準。
