# 就到站 · 香港巴士

繁體中文巴士到站 PWA，可在 iPhone Safari、Android Chrome 使用及加入主畫面。

頁首及瀏覽器標題顯示同一版本編號，按建置時的香港時間自動產生（YYYY.MM.DD-HHmm）；可用 VITE_APP_VERSION 指定版本。回報問題時請連同版本及「查看連線詳情」截圖。錯誤詳情只保留在目前頁面，不上傳裝置或位置資料。

## 功能

- 九巴／龍運、城巴路線搜尋，支援路線號碼、起點和目的地。
- 車站／地點搜尋：以站名包含的地點或車站編號找九巴／龍運車站，選站後列出途經方向及特別班次，直接查看該站到站預報。同名車站分開顯示，可載入更多結果；不提供地址定位或城巴中途站搜尋。
- 各方向車站、九巴特別班次、最多未來三班預報，每 30 秒更新。
- 收藏指定路線、方向及上車站；附近及學校路線卡可直接按星星，保存在目前瀏覽器，不跨裝置同步。允許定位後，在附近、學校、收藏及路線車站顯示距你的約略直線距離（不是步行路線距離）。
- 預設開啟附近路線，請求單次定位搜尋 300 米內九巴／龍運及綠色小巴車站（各最多 20 個），排除不能由附近街道步行進入的城門隧道轉車站，自動列出途經路線及即時到站，按最快到站排序，同路線同方向只顯示最近上車站及最多三班預報；每 30 秒更新，附倒數及立即更新按鈕（同時重新定位及載入路線／到站資料）；開頁首 30 秒內失敗項目每 5 秒重試，不重疊發出未完成請求；更新失敗保留舊資料及標示時間；未有預報排最後。
- 附近路線支援頁頂單指下拉更新：拉到提示後放手，重新定位並更新巴士資料；短拉、橫滑、多指及頁面中段捲動不觸發。
- 「放學啦」（原「李炳中學」）分頁：以「李炳中學門口」（TW310／TW311）及「對面車站」（TW496）兩個按鈕分開列出可風中學九巴／龍運車站的路線，按最快到站排序，每條路線每個方向最多三班，附每 30 秒更新、倒數、立即更新及失敗時保留舊資料，無需定位。
- 頁首「加入主畫面」旁的 QR code 按鈕可顯示固定正式網址 https://lp-ict.github.io/hk-bus/ 的二維碼，使用本站圖檔並支援離線快取。
- PWA 主畫面圖示、離線應用外殼。即時到站不會離線快取。
- 少於或等於一分鐘顯示「即將到站」；無預報不推斷停駛，只有巴士公司明確標示才顯示「服務已結束」。附近、學校、收藏及路線到站面板更新失敗保留上次結果，顯眼標示舊資料及上次成功更新時間。

城巴附近車站、新大嶼山巴士、港鐵接駁巴士、紅色小巴及跨裝置同步不在目前範圍。綠色小巴已支援路線、車站、收藏、附近預報及起點／目的地搜尋。

新增「返學啦」分頁：列出去聖公會李炳中學的九巴／龍運直達路線，優先顯示起點附近 1 公里內上車的路線，各組按最快到上車站排序，每條最多三班；落車站限定已核對的可風中學三站。定位失敗可先查看所有到校路線，或自行選擇起點。

「搜尋路線」保留路線／車站搜尋，另有「起點 → 目的地」模式。地點查詢使用地政總署 locationSearch 公開接口，失敗時嘗試巴士站名稱。使用者須選定地點；上車站距起點最多 1 公里，落車站距目的地最多 400 米（直線），配對正確站序的九巴／龍運及綠色小巴直達路線；沒有直達時提供最多 12 個轉一次車方案。轉車站直線相距不超過 200 米，隧道轉車站只接受同一站 ID；不保證行人通道或班次銜接。第二程顯示目前預報，不是乘客抵達後班次。位置查詢文字會傳給地政總署；GPS 座標只在裝置配對車站。新結果每 30 秒更新，失敗保留舊預報，支援收藏上車站。

## 技術

React 19、TypeScript、Vite 7、Bun。前端直接讀取官方公開 JSON，無需 API 金鑰或應用後端。官方端點支援 CORS。部署為靜態 `dist/`，可移植至其他 HTTPS 靜態託管服務。

- `src/lib/bus.ts`：官方資料轉換、方向／車站序號／班次篩選、距離計算。
- `src/pages/bus-app.tsx`：路線、到站、收藏、定位及安裝指引。
- `src/bus.css`：手機及桌面版外觀。
- `public/manifest.webmanifest`、`public/icons/`：PWA 資訊及圖示。
- `scripts/build-sw.ts`：建立版本化離線應用外殼，只快取本站資源，不快取到站 API。
- `.openai/hosting.json`：Sites 託管識別及靜態輸出設定。
- `server.ts`、`zosite.json`：保留原 Zo 開發框架及設定；Sites 靜態部署不使用此伺服器。

## 資料來源

- 九巴／龍運：https://data.etabus.gov.hk/v1/transport/kmb
- 城巴：https://rt.data.gov.hk/v2/transport/citybus
- 九巴開放數據及規格：https://data.gov.hk/tc-data/dataset/hk-td-tis_21-etakmb
- 城巴開放數據及規格：https://data.gov.hk/tc-data/dataset/ctb-eta-transport-realtime-eta

路線和車站資料在瀏覽器暫存 24 小時，到站資料每次向巴士公司即時查詢。按方向、車站序號及九巴服務類別篩選預報，避免循環路線同站重複或反方向資料混用。沒有預報不等同取消班次。此為非官方應用程式。

資料請求使用 AbortController 和計時器限制每次連線 18 秒，兼容沒有 AbortSignal.timeout 的瀏覽器。連線、HTTP 或資料格式失敗時，使用新查詢參數及 no-store 自動重試一次，避免重用失敗回應；兩次均失敗才交由畫面顯示錯誤及保留舊資料。

每次建置會下載官方九巴路線、車站、路線車站及城巴路線列表到 dist/bus-data；任何下載失敗會中止建置。官方接口失敗時可從本站載入這些備援列表，畫面標示資料日期。九巴單一路線車站可從完整備援列表按路線、方向及服務類別篩選；城巴各站詳情仍需官方連線。備援是發佈當日的路線／車站資料，不會自動每日更新；只有重新建置發佈才更新。即時到站預報不設副本或離線快取，連線失敗時清楚標示，不以備援冒充預報。

## 私隱

不要求註冊，不收集位置。開啟網站及按立即更新時會請求定位，首次失敗於首 30 秒內每 5 秒重試，不設重新定位按鈕或獨立車站列表；位置由裝置讀取，在裝置計算距離，不上傳到我們的伺服器。直接呼叫巴士公司 API 時，對方可見一般網絡連線資料。收藏及路線快取只在瀏覽器 localStorage；清除網站資料會移除收藏。

## 開發及驗證

```sh
bun install
bun run build
bunx tsc --noEmit
bun test
```

`bun run build` 產生 `dist/`，並建立 service worker。須在 HTTPS 或 localhost 使用 PWA；即時到站及首次下載路線需要連線。Zo 原有開發伺服器由平台管理，不應手動啟動 `bun run dev` 或 `bun run prod`。

原始碼儲存庫：https://github.com/lp-ICT/hk-bus 。網站：https://lp-ICT.github.io/hk-bus/ 。GitHub Pages 從 gh-pages 分支發佈建置後的網站；更新 main 後須重新驗證、建置並更新 gh-pages。以 `BASE_PATH=/hk-bus/ bun run build` 建立 GitHub Pages 版本；預設路徑仍適用其他靜態託管。

學校車站位置核對：https://liping.edu.hk/page/653 。校外站往荃灣／葵涌，對面站往沙田；站號及路線對應以九巴官方 stop、route-stop API 為準。

## 綠色小巴資料

官方即時預報：https://data.etagmb.gov.hk ，規格：https://data.etagmb.gov.hk/static/GMB_ETA_API_Specification.pdf 。
車站座標使用運輸署整批資料：https://static.data.gov.hk/td/routes-fares-geojson/JSON_GMB.json 。

建置先執行 Python scripts/build-gmb-data.py（需要 requests），下載路線、方向及逐線站序，以整批座標配對相同 stopId，減少大量逐站請求。24 小時下載快取位於 .gmb-cache（不提交）；任何路線或站序下載失敗會中止建置。產生 public/bus-data/gmb-network.json 並複製到 dist。整批座標表未有的新站會從官方逐站接口補齊，失敗則中止建置；不發佈缺少座標的快照。位置資料異常時距離回傳 Infinity，不參與位置或轉車配對。配對保留官方只准上車／只准落車限制。路線 ID 及方向保留官方值；不同地區相同號碼不混用方向。路線快照只在重新建置發佈時更新，即時 ETA 不快取。

## 校章及定位備援

頁首校章使用使用者提供的 PNG，保留原比例，網頁版本 public/school-crest.png 為縮小圖，隨應用外殼離線快取；安裝圖示維持原有巴士圖示。
附近路線仍預設裝置定位（允許最多 10 秒），顯示瀏覽器報告的精確度。查不到 300 米內車站時不斷言實際附近無車，首 30 秒繼續重試，並提供手動地點選擇。定位精確度超過 500 米也可選地點；選定後立即更新會沿用選定位置，使用裝置定位按鈕可切回，手動位置不跨頁面重載保存。無法從伺服器確認個別電腦實際回傳位置，請以畫面提示及實機驗證為準。
放學啦分門口／對面兩組，各有全部／巴士／小巴篩選，不設獨立附近小巴站。312 官方資料缺少學校分站，按使用者確認補充門口往梨木樹、對面往青衣站（青衣城）；門口沿用 GMB:20001848 座標，對面以 TW496 座標約略定位，使用 GMB:LOCAL-312-OPPOSITE 本地識別。補充站序使用 4.5／1.5 作配對，不是官方 ETA 序號；所有到站入口必須保留 etaAvailable=false，不向官方查詢補充站預報或套用其他站時間。官方將來提供對應資料時應取代補充。附近路線分別保留最近 20 個巴士及 20 個小巴站，避免巴士站數量擠走小巴。返學啦落車站擴充為三個已核實九巴站及學校 400 米內小巴站，保留不以隧道轉車站作到校站的限制。附近小巴站距離為直線，不能保證行人通道。官方未列出的沿途招手上落點不虛構站序或即時預報。

每個分頁及路線詳情共用裝置位置列：顯示定位中／失敗、座標、精確度及香港時間；附近有站時顯示鄰近站名（不是確切地址）。GPS 與車站資料載入狀態分開，資料接口失敗不冒稱定位失敗。手動查詢位置另行標示，不當作手機位置；更新失敗保留上次定位並標示。座標不傳送到地址查詢服務。
